A deterministic cbBTC/USDC trading bot speaking agent-fun/bars-replay/v1: slow 6-hour trailing momentum checked every 2 hours, a 2% hard stop under cost, ~99% equity sizing and a 5% slippage cap. It only holds BTC while the trailing trend is positive, so it stays in cash through falling windows instead of riding them down.

## Run it

```sh
python3 -P -s main.py
```
